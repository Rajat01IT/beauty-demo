# Makeover by Antima

A premium single-page React + Vite demo website for Makeover by Antima, Gangashahar, Bikaner.

## Run locally

```bash
npm install
npm run dev
```

Service and gallery demo content lives in `src/data/services.js` and `src/data/gallery.js`. Business facts are centralized in `src/data/businessData.js`.
